# Student Management System in C

A console-based Student Management System developed in C.

## Features

- Add Student
- Display Students
- Search Student by Roll Number
- Update Student Details
- Delete Student
- Exit

## Concepts Used

- C programming
- Structures (`struct`)
- Arrays
- Functions
- Loops
- Conditional statements
- String handling

## How to Run

1. Open `student_management.c` in a C compiler such as GCC, Code::Blocks, Dev-C++, or VS Code with a C compiler.
2. Compile the program:

```bash
gcc student_management.c -o student_management
```

3. Run it:

```bash
./student_management
```

On Windows with GCC:

```bash
student_management.exe
```

This project is created as a separate C project repository and is independent of the College Campus project.
